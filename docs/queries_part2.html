List existing package grants.
Either packageId or organizationId must be specified.

The following examples assume that the caller is the owner of the Packages:
packageGrants(id: 123) - Show Grants for Package 123
packageGrants(organizationId: 12) - Show Grants for all Packages to Org 12
packageGrants(id: 123, organizationId: 12) Show Grants for Package 123 to Org 12

basicUserInfo(id: ID!): BasicUserInfo

Retrieve the basic user information.
The caller and the queried user are required to be members of the same organization,
unless the caller is superadmin user.
Example:
Request:
query {
basicUserInfo(id: "267de7e1-efb2-444a-a524-210328b78503") {
id
name
firstName
lastName
email
imageUrl
}
}
Response:
{
"data": {
"basicUserInfo": {
"id": "267de7e1-efb2-444a-a524-210328b78503",
"name": "username",
"firstName": "first",
"lastName": "last",
"email": "email@test.com",
"imageUrl": null
}
}
}
