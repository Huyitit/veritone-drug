Retrieve a list of ingest slugs with optional filtering and pagination.

This query supports complex filtering on status, file URIs, time ranges, and other attributes.
Results are paginated and sorted by createdAt ascending. Default offset is 0 and limit is 30.
The results are automatically filtered to the user's organization from their authorization context.

Filter supports:

  • sourceId/sourceIds: Filter by media source
  • status: Filter by ingestion status (pending, uploaded, ingested, failed, etc.)
  • fileUriExact: Match exact file URIs
  • fileUriPrefix: Match file URIs by prefix (case-insensitive)
  • bundleKey: Group files by bundle identifier
  • batchFileUri: Associated batch file URI
  • tdoId/assetId: Filter by associated temporal data object or asset
  • mimeType: Filter by file MIME type
  • updatedFromTime/updatedToTime: Filter by update time range
  • updatedFromTimeExclusive/updatedToTimeExclusive: Use exclusive comparison operators
